# A Copy of a Copy — Sound-Ripple Comparison Version

## Run in VS Code

1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Move the browser window to the projector and press `F` for fullscreen.
4. Press `H` to hide or show all interface labels.

No external library or internet connection is required.

The layout responds to desktop, tablet, mobile portrait and mobile landscape viewports. Mobile browsers use the live visual viewport height so address-bar changes do not stretch or crop the canvas; controls respect safe areas and the sound selector becomes a touch-friendly bottom strip.

## Colour system

- Near-white / very pale ice blue — high-key projection field
- Ink navy — stable Chinese source glyph with maximum contrast
- Cyan → cobalt → violet — live waveform gradient
- Cobalt and sky blue — displaced particles
- Medium and pale blue — English copies

## Interaction

- Move the mouse: particles scatter away from the cursor and return to the Chinese glyph.
- Move faster: stronger displacement.
- Click: one expanding waveform-shaped ripple, particle burst and the selected Cantonese recording.
- The permanent horizontal sound wave is removed. Sound now appears only as a radial, oscillating contour generated by interaction.
- Multilingual labels around the source glyph show possible listening responses in English, Japanese, Korean, French, German, Spanish and Italian.
- These words drift continuously with independent buoyancy, depth and water resistance; pointer movement and click waves carry them through the liquid field.
- `1`–`5`: 詩 / 星 / 買 / 心 / 飯.
- `Space`: trigger a central burst.
- `R`: rebuild/reset the glyph.
- `F`: fullscreen.
- `H`: hide/show the projection controls.

The project includes the five supplied Cantonese recordings in `audio/`. If a browser cannot decode an M4A file, the page automatically falls back to a short synthetic cue. All multilingual responses are cross-language sound-alikes / near-homophones and listening prompts—not exact phonetic equivalents or translations.

All five recordings are preloaded when the page opens. When run with VS Code Live Server, Web Audio analyses each recording, estimates its noise floor, detects the first sustained voice onset, and starts about 25 ms before it. This removes leading silence without cutting off the consonant. Browsers usually block this analysis on a `file://` page, so that mode falls back to cached audio with a 0.06-second trim.
